# 使用指南

[文档索引](README.md) · [配置参考](CONFIGURATION.md) · [维护与备份](MAINTENANCE.md)

## 首次设置

首次打开时创建管理员账户，再确认下载方式、保存目录和同步周期。Docker 默认使用内置 BT 下载器，不需要另装 qBittorrent；源码运行默认直链。

向导会检测保存目录能否写入，但不会创建缺失目录，也不会新增 Docker 挂载。网页里保存的设置优先于启动时的环境变量。

## 搜索与订阅

1. 在「搜索」输入番名，先确认 Bangumi 条目（作品、季度或续作）。
2. 展开条目，查看聚合服务返回的候选资源。可按标题关键词、来源、字幕组和清晰度筛选；筛选只作用于已返回的结果，不改订阅规则。
3. 在合适的资源旁点击「订阅此版本」，核对匹配预览、番剧归属、自动下载和保存位置后确认。

订阅后立即同步一次，之后按同步周期查找新集。追更按所选资源的番名、字幕组、清晰度、字幕语言和标题季号匹配；字幕组改名或换版本不会自动跟随。聚合结果可能缺少早期集数，不保证补齐全季。

聚合服务的部署与隐私说明见[在线聚合搜索服务](SEARCH_SERVER.md)。

### 手动 RSS

在「订阅管理」可以直接填写你有权使用的 RSS 地址，或导入 OPML。保存前先预览匹配结果。

| 规则 | 说明 |
| --- | --- |
| 包含关键词 | 逗号分隔，必须全部命中 |
| 排除关键词 | 任一命中即排除 |
| 季数条件 | 不限 / 仅未标明 / 指定季；指定季可额外接受未标明季号的资源 |
| 集数偏移 | 新订阅首次同步时自动推断，例如最小集数为 0 时 +1；可手动修改。详见[集数偏移](CONFIGURATION.md#集数偏移) |

关键词比较时统一简繁、英文大小写和全角英数字（如 `ＡＩ` 与 `AI`），不改原始标题。「简日」与「繁日」仍是不同的词。

聚合订阅和 RSS 订阅都在「订阅管理」里同步、编辑、暂停和删除。删除订阅默认保留媒体。

### 集齐自动停订

Bangumi 提供正篇总集数后，同一番剧同一季的第 1～N 集全部归档时，订阅会自动停用并标记「已集齐」。总数未知、有缺集或订阅混合多部番剧时不会停订。详见[集齐自动停订](CONFIGURATION.md#集齐自动停订)。

## 保存位置与识别

- **媒体库目录**：所有番剧文件夹的默认根目录，留空使用下载目录。
- **订阅的保存位置**：填根目录，例如 `/media`；保存时生成 `/media/<番剧名>`。
- **番剧的存储位置**：填番剧文件夹本身，例如 `/media/<番剧名>`。

同一番剧的所有订阅共用一个存储位置。自动同步只补充尚未设置的位置，不覆盖已有设置。归档结构为 `<根目录>/<番剧名>/Season XX/…`，详见[存储位置与目录映射](CONFIGURATION.md#存储位置与目录映射)。

标题识别会清理字幕组、编码、分辨率等标签，分离季号和集号，双语标题优先取中文。中英文季号、罗马数字和全角写法都能识别；合集区间不会被当作单集。识别错了可以在条目「调整」里改归属的番剧、季号和集数，已保存的文件默认随之移动。

归档季号的优先级：条目指定 → 番剧设置 → 标题解析 → 第 1 季。

匹配到 Bangumi 后番剧名会规范为官方名称。自动规范不会搬动已有媒体，只有空目录或只含封面/NFO 的目录会随之改名。手动在「管理」里修改名称、存储位置或季号时，会先列出需要移动的已保存文件，默认移动，也可以选择只影响之后的下载。

## 最近条目与下载

| 状态 | 含义 |
| --- | --- |
| 待下载 / 排队中 | 等待执行名额 |
| 等待下载器 | 下载器未就绪或不支持该资源，检查配置 |
| 下载中 / 已发送到下载器 | 正在下载，尚未归档 |
| 已暂停 | 保留任务和进度，可继续 |
| 下载失败 | 查看原因，修正后重试 |
| 已保存 | 已归档完成 |

列表每页 100 条，可见时每 5 秒刷新；状态数量是全库统计。支持单条或批量下载、重试、暂停、继续和移除记录。「下载控制」可调整并发数（1–32，默认 2）。

- 暂停的任务在同步和重启后保持暂停，继续时恢复原任务。直链继续会从头下载。
- 磁力获取元数据、种子校验都不算视频完成，只有「已保存」才是。
- 移除条目记录默认保留已保存的媒体；勾选「同时删除硬盘上的文件」并再次确认才会删除。

## 番剧库

番剧库汇总所有番剧，可按名称搜索，按星期、已完结、收藏状态和资源范围筛选，按最近收录、名称、资源数量、评分或更新日排序，支持海报墙和信息卡片两种展示。筛选条件写在地址里，刷新后保持。

**更新日**：默认取 Bangumi 标注的放送星期；条目没有标注时，用 Bangumi 每日放送表补充当季在播的番剧。「播放结束」日期已过的归入「已完结」。还没下载的收藏也一样，同步后由后台逐个读取条目补全，收藏较多时需要几分钟。也可以在番剧「管理」里手动指定星期，手动值优先。仍然无法确定的归入「待补充」。更新日表示放送安排，不代表字幕组当天出片。

**Bangumi 收藏**：在「设置 → Bangumi」连接账号后，「想看、在看、看过、搁置、抛弃」五种收藏状态会单向同步到番剧库。已有本地番剧对应同一 Bangumi 条目时合并显示；还没下载的收藏单独显示为卡片。远端取消收藏不影响本地番剧、订阅和媒体。详见 [Bangumi 收藏同步](CONFIGURATION.md#bangumi-收藏同步)。

**详情**：点击番剧打开详情，可查看简介、放送日期、集数、Bangumi 评分与排名，以及已保存的资源和下载状态。从这里可以播放、下载已有资源，或点「找资源并选择下载」去搜索新版本。打开详情本身不会订阅或下载。本地番剧点「管理」打开管理面板：

- **基本信息**：名称（也是文件夹名）、更新日；高级里有搜索词和多来源规则。
- **位置与季号**：存储位置和默认季号（0 表示按标题识别）。有已保存文件需要换位置时，保存前会显示数量和新旧目录，默认移动文件；移动在后台进行，进度显示在详情里，失败的文件保留在原位置。
- **元数据**：查看当前是手动绑定、自动识别还是未匹配；可以搜索并绑定 Bangumi 条目，或恢复自动识别（手动绑定会先解除）。
- **合并与删除**：合并时资源与订阅归入目标番剧，可同时把文件移到目标番剧的文件夹；删除番剧默认保留硬盘上的文件，下载器里对应的任务会移除但保留其文件。勾选删除文件后需要再次确认。

Bangumi 自动匹配错了，可以手动绑定条目或修改搜索词。Bangumi 不可用时不影响订阅和下载。

快捷键：`/` 聚焦搜索，批量管理时按 `Esc` 退出。

## 播放

浏览器直接播放归档文件，支持断点续播。不转码，也不渲染外挂字幕；浏览器无法解码的格式请用外部媒体服务器，扫描目录指向归档目录而不是下载器的源文件目录。

## 设置与备份

设置按「下载方式、媒体库、网络与同步、管理员账户、Bangumi、版本更新」分组，可用 `?tab=` 直接打开对应分组。每组单独保存（`Ctrl/⌘+S`），离开前会提醒未保存的修改。

「服务与备份」菜单（手机在顶部菜单）提供运行状态、JSON 备份与恢复和 OPML 导入。JSON 备份只含配置和订阅，不含历史条目、下载任务和媒体文件。完整备份与更新见[维护指南](MAINTENANCE.md)。
