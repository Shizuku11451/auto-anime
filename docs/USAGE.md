# 使用指南

[文档索引](README.md) · [配置参考](CONFIGURATION.md) · [维护与备份](MAINTENANCE.md)

## 首次设置

首次访问未初始化实例时创建管理员账户，确认下载方式、保存目录和同步周期。搜索使用 Bangumi 条目与独立在线聚合服务，不再配置 RSS 搜索模板。Docker 与 Windows 默认内置 BT 下载器（不需要 qBittorrent）；其他平台源码运行默认直链。已保存数据库设置优先于启动环境变量。

向导读取部署默认值，读取失败须重新加载后再保存。部署根目录可检测临时文件的写入、同步与删除；检测不创建缺失目录，也不会新增 Docker 挂载。未映射或无法确认时需要人工核对。已配置完整账户的部署直接进入登录。

## 搜索与订阅

1. 在「搜索」输入番名，先查看 Bangumi 番剧条目，确认作品、季度或续作。
2. 展开条目后，在线聚合服务查询已配置来源，并把候选种子显示在条目下面。实例管理员需先配置独立服务，未配置不影响浏览 Bangumi；部署见[在线聚合搜索服务](SEARCH_SERVER.md)。
3. 在所需种子旁点击「订阅此版本」，核对匹配预览、番剧归属、自动下载和保存位置，勾选版本确认后保存；无需填写 RSS。也可复制磁力链接或打开来源页。名称匹配不代表季度或续作已经确认。

候选资源支持按标题关键词、来源站点、字幕组 / 发布组和清晰度组合筛选，各条件同时生效；标题关键词忽略英文大小写及全角差异，可用于查找「简日」「HEVC」「合集」等原始标题内容。下拉选项来自本次完整结果，未识别字段可单独筛选；跨站去重的资源命中任一来源即可显示。列表显示匹配数 / 总数，没有匹配时调整条件或点击「重置筛选」。切换番剧或重新加载资源会清空条件；仅筛选已返回资源，不额外搜索、不改变订阅规则，来源失败和截断警告始终保留。

聚合订阅会立即同步一次，之后按已设置的周期通过在线服务查找新集，按磁力哈希去重；不只是下载当前种子。按所选资源解析番名、字幕组、清晰度、已识别的字幕语言和标题季号追更；未识别的字幕语言、编码等如需限定，可补充包含/排除词并重新预览。命名或字幕组变化不会自动换版本。默认保留原始集号，累计编号等情况可手动调整集数偏移；聚合结果可能缺少早期集数，不保证补齐全季。搜索结果只有来源页、没有有效磁力或无法解析番名时不提供订阅。

旧的「RSS 搜索与订阅」模式已移除，已有 RSS 订阅、同步及下载不受影响；仍可在「订阅管理」手动添加你有权使用的实际 RSS 地址。聚合订阅也在此管理，支持同步、编辑、暂停和删除；删除订阅默认保留媒体。

订阅弹窗展示订阅名称、RSS 地址、归入番剧、自动下载与匹配预览。需要修改关键词或季数时展开「筛选规则」，核对自定义目录时展开「来源与保存位置」；折叠不清空已有设置。

添加 RSS 时先预览。包含关键词以逗号分隔，要求全部命中；排除关键词任一命中即排除。比较时统一简繁文字、英文大小写和全角英数字（如 `ＡＩ` / `AI`、`１０８０ｐ` / `1080p`），不改原始标题或规则；「简日」与「繁日」仍不同。手动规则不会自动推断别名或拼音。

订阅的季数条件独立于归档季号：不限、仅未标明、指定季；指定季可在核对后额外接受未标明资源，仍不接受其他季或冲突资源。订阅搜索和状态筛选只改变列表展示。

## 保存位置与识别

- 媒体库目录是所有番剧文件夹的默认根目录，留空使用下载目录。
- 订阅「保存位置」填根目录，例如 `/media`；保存时生成 `/media/<番剧名>` 并写入该番剧的位置。
- 番剧或条目的「存储位置」填番剧文件夹，例如 `/media/<番剧名>`，不是公共根目录。
- 同一番剧共用存储设置，不是每个 RSS 一份互不相干的目录。同步时只补充尚未指定的位置，不覆盖已有番剧设置。详见[目录规则](CONFIGURATION.md#存储位置与目录映射)。

标题识别清理字幕组、片源、编码、分辨率、语言和校验标签，分离季集，双语标题优先中文片段。支持常见中文、英文季号及明确罗马数字，也识别 `Ｓ０２Ｅ０３`、`第２季`、`Season-02`、`Season.02`、`S 02`、`Second Season` 等写法；搜索结果、订阅预览、同步和归档共用这些规则。合集区间不强行当作单集。原始资源标题保留，错误可人工纠正。

归档季号优先级：条目指定 → 番剧设置 → 标题解析 → 第 1 季。订阅季数过滤不会直接改写归档季号。无法明确编号的资源保留非单集布局，不承诺逐文件解析复杂合集。

匹配 Bangumi 后规范番剧名；已有媒体目录不自动搬迁，仅空目录或只含封面/NFO 的目录可能随改名重命名。修改位置不会迁移旧媒体；已保存条目可通过「纠错」明确选择迁移。没有批量归档迁移功能。

## 最近条目与下载控制

列表按服务端搜索/状态筛选，每页最多 100 条，上下均可翻页。状态数量是全库统计，不是当前页条数；可见页面每 5 秒刷新，也可手动刷新。

| 状态 | 含义与操作 |
| --- | --- |
| 待下载 / 排队中 | 尚未占用执行名额，可加入下载队列 |
| 等待下载器 | 当前模式不能处理该资源或下载器尚未可用，检查配置 |
| 下载中 / 已发送到下载器 | 已开始或已提交，不代表归档成功 |
| 已暂停 | 保留原任务身份和进度，可继续 |
| 排队中 · 继续 / 继续中 | 等待名额或核对下载器恢复结果，不应重复提交 |
| 下载失败 | 查看原因、修正配置，再重试 |
| 已保存 | 文件完成归档且数据库提交成功 |

「下载控制 → 调整并发」范围 1–32，默认 2；降低上限不打断已有任务。支持单条、批量下载/重试、暂停、继续及移除记录。全选只选当前页，搜索、筛选和翻页清空选区；部分失败保留选中供重试。

暂停保留任务所属下载器，切换默认模式不迁移旧任务；同步与重启不会自动继续已暂停任务。直链继续从头下载，界面上的旧进度不代表断点续传。磁力获取元数据和种子校验不是视频完成。

「详情」展示原始标题、时间、下载方式和归档位置，可纠错、调整位置或移除。移除条目记录不删除已保存媒体；不要把数据库记录删除当作磁盘清理。

## 番剧库与播放

番剧库支持名称、收藏状态、资源范围、星期（含已完结）与日期筛选，按最近收录、名称、资源数量、评分或更新日排序，默认海报墙展示，可切换信息卡片。筛选与排序写入地址，刷新或返回后保持；展示方式记在本机浏览器。卡片进度条表示已保存资源占全部资源的比例，不代表观看进度。连接 Bangumi 后，五种收藏状态单向同步到番剧库；同一 Bangumi 条目与本地番剧合并显示（手动绑定优先，未绑定时使用资料自动识别到的条目；一个条目只合并到一部本地番剧），收藏状态不代表本地下载或播放进度。尚未下载的收藏在封面悬停时显示同步时缓存的 Bangumi 简短简介，重新同步后更新。点击番剧先展开详情，查看收藏状态、应用内关联的已保存资源和下载状态，再选择播放、下载已有资源，或点击「找资源并选择下载」进入 Bangumi 搜索并查看聚合资源，确认版本后可订阅；打开详情不会自动订阅或下载，也不扫描磁盘上的其他文件。仅云端收藏不参与批量合并或删除；远端移除收藏不影响本地番剧、订阅和媒体。本地番剧详情还提供资料绑定、规则管理、编辑、合并与删除；需要删除媒体时确认独立的删除选项。

桌面端「每周追番」使用单行筛选条，选中背景随星期切换平滑滑动；搜索、资源范围、排序与视图切换集中在同一工具栏，指定日期在「按日期」中展开。连接 Bangumi 后，工具栏下方显示带数量的收藏状态标签，只列出有番剧的状态。手机端自动换行，星期与收藏标签可横向滚动；开启系统「减少动态效果」时不播放滑动动画。按 `/` 聚焦搜索，批量管理时按 Esc 退出；空库和加载失败提示采用紧凑卡片。

更新日默认读取 Bangumi 明确的放送星期；条目未标注或标注多日时，退回 Bangumi 每日放送表（仅当季在播条目），仅云端收藏也在同步时按放送表补充。可手动指定周一至周日，改回自动后跟随资料。已获取的星期缓存 7 天，未获取的次日重试；Bangumi「播放结束」日期早于今天的归入「已完结」（手动指定更新日时仍按手动值）；仍未知、多日或不定期放送归入待补充。指定日期按浏览器本地星期筛选，不是历史到片记录，不推断完结或收集完整度。

Bangumi 匹配错误可手动绑定或修改元数据搜索词；服务不可达不阻塞基础订阅和下载。本地 NFO 不代表第三方已校验全部资料。

封面右上角显示 Bangumi 社区评分，无评分则隐藏。点击番剧展开详情，可查看简介、放送日期、正篇集数、评分人数、排名及 Bangumi 原条目；这些是公开资料，不是个人打分或本地观看进度。详情每次打开按需获取，资源自动刷新不会反复拉取资料。资料加载失败时点击「重试资料」，本地资源区仍可独立使用；旧收藏没有评分时，可在设置页手动同步。

播放器直接提供媒体流与浏览器断点续播，不转码或渲染外挂字幕。浏览器不支持编码时使用外部媒体服务器；将服务器扫描目录指向已归档媒体，而不是下载器源文件目录。

## 设置与服务工具

设置分为下载方式、媒体库、网络与同步、管理员账户、Bangumi、版本更新，地址中的 `?tab=` 可直达对应分类。每个分类独立保存：「保存」（或 Ctrl/⌘+S）只提交当前分类，「撤销」确认后恢复当前分类。切换分类或离开页面时，未保存的修改需确认放弃；校验失败定位到对应字段；加载失败不能保存默认值。Bangumi 连接与同步单独操作，无需保存。

桌面「服务与备份」与手机顶部菜单提供状态、JSON 备份/恢复及 OPML 导入。主题默认跟随系统，手动选择保留在当前浏览器。备份与更新不是同一操作，详见[维护指南](MAINTENANCE.md)。
