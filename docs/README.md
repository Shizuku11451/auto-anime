# 文档索引

本文档集按当前工作区源码与配置核对（2026-10-14）。实现说明不是远端制品发布状态或完整安全、性能及 NAS 兼容性认证。

适配目标为飞牛 fnOS、Linux 和 Windows：飞牛 NAS 为主要维护重点，Linux 提供服务端部署，Windows 10/11 x64 为次要适配。完整范围与架构验收边界见 [README 平台适配范围](../README.md#平台适配范围)；其他 NAS 品牌与 macOS 暂不承诺专门适配。
