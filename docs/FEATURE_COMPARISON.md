# 功能边界

[文档索引](README.md) · [使用指南](USAGE.md)

本项目状态按 2026-10-14 当前工作区源码核对。本页说明当前已实现与未实现的范围，不将历史路线图作为当前产品说明。

## 已实现与限制

| 领域 | 当前实现 | 不应误解为 |
| --- | --- | --- |
| 找番 | 三个内置来源、自定义模板、季数有限扩展、版本筛选、预览订阅 | 全网聚合、全集保证或多 RSS 联合订阅 |
| 过滤与识别 | 简繁等价关键词、季集解析、合集区间保护、规范番名、手动纠错 | 别名全覆盖、任意合集逐文件识别或 AI 解析 |
| 任务控制 | 排队、并发、进度、暂停/继续、重启恢复、明确任务归属 | 直链断点续传、速度限额、任意任务自动迁移 |
| 归档 | 标准季集目录、提交恢复、单条纠错迁移、源文件保护与可选清理 | 批量迁移、字幕配对、自动洗版或媒体库扫描 |
| 去重 | 资源 URL 去重及下载器任务身份核对 | 同季同集的统一版本择优与修正版升级 |
| 元数据 | Bangumi 资料、封面、手动绑定、每周更新日 | TMDB 完整季集映射、完结判断或收集完整度 |
| 展示与播放 | 番剧库、服务器端条目分页、亮暗/手机界面、浏览器播放 | 转码、外挂字幕渲染、媒体服务器刷新或观看进度联动 |
| 管理 | 单管理员、Basic Auth、JSON 配置恢复、OPML、Webhook | 多用户、独立 API 令牌、多渠道通知或完整网页灾备 |
| 部署更新 | Docker、Windows 桌面打包、实验性 FPK、校验后程序更新 | 全部制品已发布、所有 NAS 已验收或一键回滚 |

尚未实现的能力不是发布承诺。是否开发应依据具体需求及数据安全成本。
