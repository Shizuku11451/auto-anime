# 功能边界

[文档索引](README.md) · [使用指南](USAGE.md)

本页列出当前版本已实现的功能和尚未支持的范围。未列出的能力不代表已在计划中。

| 领域 | 已实现 | 尚未支持 |
| --- | --- | --- |
| 搜索与订阅 | Bangumi 条目搜索、多来源聚合资源、确认版本后订阅追更、手动 RSS、OPML 导入 | 无需确认的自动匹配、保证补齐全季 |
| 过滤与识别 | 简繁等价关键词、季集解析、集数偏移推断、合集区间保护、手动纠错 | 别名全覆盖、复杂合集逐文件识别 |
| 下载 | 内置 BT、qBittorrent、Aria2、Transmission、直链；排队、并发、暂停/继续、重启恢复 | 直链断点续传、限速 |
| 归档 | 标准季集目录、NFO 与封面、单条纠错迁移、源文件保护与可选清理、做种完成后清理任务 | 批量迁移、字幕配对、自动洗版、通知媒体服务器刷新 |
| 去重 | 资源地址去重、下载器任务身份核对 | 同集多版本择优、修正版自动替换 |
| 元数据 | Bangumi 资料与封面、手动绑定、放送星期、已完结判断、正篇集数与集齐停订、收藏同步 | TMDB 资料、完整季集映射 |
| 番剧库与播放 | 星期/已完结/收藏筛选、海报墙、亮暗主题与手机布局、浏览器播放与续播 | 转码、外挂字幕、观看进度同步 |
| 管理 | 单管理员、JSON 配置备份、Webhook | 多用户、API 令牌、多渠道通知 |
| 部署 | Docker、飞牛 FPK、Windows 桌面版、程序内更新 | 一键回滚、飞牛以外的 NAS 专门适配 |
